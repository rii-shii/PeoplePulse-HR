# PeoplePulse-HR 📊

## Employee Attrition & Workforce Analytics

A Python data analytics project exploring employee attrition, departments, overtime, job roles, age, income, and years at the company.

## Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Dataset
IBM HR Analytics Employee Attrition dataset. The dataset contains 1,470 employee records and 35 columns.

## Key Finding
The overall attrition rate is 16.12%: 237 employees left out of 1,470.

## Analysis
- Overall employee attrition distribution
- Attrition rate by department
- Attrition rate by overtime
- Attrition rate by job role
- Age, monthly income, and years at the company by attrition status

## How to Run
1. Download the dataset and place the CSV at `data/raw/WA_Fn-UseC_-HR-Employee-Attrition.csv`.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open `hr_analysis.ipynb` in VS Code and run the cells.

The raw dataset is not included in this repository.
